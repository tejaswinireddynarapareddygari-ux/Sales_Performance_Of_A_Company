# Sales Performance of a Company

## 📌 Project Overview

This project analyzes a company's sales data using Microsoft Excel to create an interactive dashboard that helps track business performance. The dashboard provides insights into sales trends, product performance, regional sales, and key business metrics to support data-driven decision-making.

---

## 🎯 Objective

- Analyze sales performance using Excel.
- Identify sales trends and business growth.
- Monitor key performance indicators (KPIs).
- Build an interactive dashboard for better business insights.

---

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Functions

---

## 📂 Dataset

The dataset contains company sales information such as:

- Order ID
- Order Date
- Customer Details
- Product Category
- Product Name
- Region
- Quantity Sold
- Sales Amount
- Profit
- Discount

---

## 📊 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Monthly Sales Trend
- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Top Performing Products
- Interactive Filters using Slicers

---

## 📈 Key Insights

- Identified the highest-performing products and categories.
- Compared sales performance across different regions.
- Analyzed monthly sales trends and revenue growth.
- Evaluated overall business performance using KPI metrics.
- Built an interactive dashboard for easy decision-making.
